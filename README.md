# AddressesExample

Beispielhafte Implementierung der Übungsaufgabe "Adressen REST API einlesen" in Objective-C.

## Komponenten

* [Mantle](https://github.com/Mantle/Mantle) - Model framework for Cocoa and Cocoa Touch
* [MTLManagedObjectAdapter](https://github.com/Mantle/MTLManagedObjectAdapter) - Core Data support for Mantle
* [AFNetworking](https://github.com/AFNetworking/AFNetworking) - A delightful networking framework for iOS, macOS, watchOS, and tvOS
* [Overcoat](https://github.com/Overcoat/Overcoat) - The perfect accessory for Mantle and AFNetworking
